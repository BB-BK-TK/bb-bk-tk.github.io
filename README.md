# bb-bk-tk.github.io

Public runtime repository for browser-delivered files only.

## Hard rule

This repository is **never** a source-of-truth repository for a private project.

Project source lives in private repositories. This public repository may contain only the minimum files a browser or WebView must download at runtime.

Allowed examples:
- deployed HTML/CSS/JS
- public images/media/assets
- public site support files such as `.nojekyll` and `.well-known/`
- intentionally public download artifacts when explicitly required

Forbidden:
- Android/native source
- Supabase/backend source, functions, migrations, SQL, or internal infra
- product docs, roadmaps, setup notes, research, or operating documents
- `.env` files, private keys, keystores, service-role keys, admin credentials, tokens, service-account files
- canonical project source copied from a private repository

## Deployment model

Human edits happen only in private source repositories.

- `BB-BK-TK/daehwateum` → `daehwateum/` runtime only
- `BB-BK-TK/FitGive` → `fitgive/` runtime only
- `BB-BK-TK/SonGyeol` → APK contains its web bundle; no public SonGyeol runtime is required
- `BB-BK-TK/team-boram-platform` → private source. The existing `team-boram/` browser runtime is a temporary exception until its access model is decided.

Runtime folders should be generated by deployment automation and should not be hand-edited.

## Intentionally public site content

- `index.html` and root assets — BoRam portfolio
- `binna/` — Binna public page
- `daehwateum/` — Daehwateum browser/WebView runtime
- `fitgive/` — FitGive browser/WebView runtime
- `team-boram/` — temporary browser runtime; not canonical source

If a file is not required by a browser, WebView, or intentionally public website, it does not belong here.
