The first world

Pixel Obby is made for one more try.

A small, colorful obstacle game built around the pleasure of learning a jump, missing it, and trying again. More little worlds are on their way.

How Pixel Obby began

First, it was a page of ideas.

Then it became a game — one question, one fix and one new idea at a time.

01

Imagine the loop

Easy to hard levels. A jump button. 100 XP for finishing. A market where XP changes your character.

02

Play, spot, fix

When the controls didn't work, Binna asked why. A tutorial, red-to-green checkpoints and a way to replay old obbies followed.

03

Make it feel like hers

More avatars and wearable items. A duck that quacks. A cactus that leaves little piles of sand on the blocks it touches.

The actual prompts

Questions became the build list.

These are Binna's own messages from the first conversations used to make Pixel Obby.

01 · Start
I wanna create a game.

The first question that opened the project.

02 · The game loop
I want to create a game where you can play various types of obbies. There are easy to hard.

Levels get harder; finishing one unlocks the next.

03 · Progress
After you finish one obby, then they get 100 more XP … with the XP they can change their character in “market”.

XP and the market gave the game a reason to keep going.

04 · Make it work
there is a glitch. it does not jump or move when i press the buttons. also provide a short tutorial available.

A bug report became better controls and a first-play guide.

05 · A clear signal
make the checkpoints red before you touch them, green after you touched them

A small visual rule made progress easier to understand.

06 · Personality
the duck avatar doesn't make a quack sound

One character detail made the world feel more alive.

Pixel Obby isn't just a game Binna plays. It's a game she keeps imagining, testing and improving.
